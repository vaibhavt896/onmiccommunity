# Design files (not shipped with the website)

- `social/exports/`: finished PNGs ready to upload (story, feed post, reel cover, WhatsApp message, Instagram and WhatsApp profile photos).
- `social/highlights/`: five Instagram highlight covers (PNG and SVG, 1080 x 1920).
- `social/templates/`: editable SVG sources. They link to `../../public/vibes/*.webp`, so keep the folder structure when editing.
- `brand-guide/onmic-brand-guide.pdf`: one-page brand and image guide.

Photos in this project are generated promotional scenes inspired by the community, not records of real events or real testimonials.
